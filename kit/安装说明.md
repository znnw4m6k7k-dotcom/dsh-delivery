# 交付模式 安装说明

给已经装好官方 DeepSeek Harness（DSH）的 Mac / Windows 用户。装好后，DSH 新会话默认是“交付”模式：先访谈确认验收标准，再计划、实现、独立验收、出报告，项目结束后可以复盘，把经你确认的经验存进行业经验包，下个同行业项目自动用上。

不需要注册账号。模型费用走你自己的 DeepSeek API Key（在 DeepSeek 开放平台充值、创建 Key）。

## 安装
1. 安装并打开一次 DeepSeek Harness。
2. Mac：双击上一层的 `Install-Mac.command`，或在终端运行 `sh install.sh`。
   Windows：双击上一层的 `Install-Windows.bat`，或在 PowerShell 运行 `powershell -ExecutionPolicy Bypass -File .\install.ps1`。
3. 完全退出 DSH（Mac 按 Cmd+Q；Windows 托盘图标右键“退出”）后重新打开。
4. 第一次使用时，在欢迎页选“添加 API Key”，粘贴你的 DeepSeek API Key。
5. 新建会话，确认智能体预设是“交付”。也可以输入 `/delivery-doctor` 自检。

遇到问题看 `docs/安装问题排查.md`。

## 使用
- 直接说要交付的成果：“帮我做一份 XX 行业的 XX 方案 / 做一个 XX 工具”。
- 它会先问几个业务问题，列出验收条目请你确认。
- 想看进度时说“打开交付工作台”，它会生成一页汇总：验收条目逐条的通过情况、冻结版本、文件有没有在冻结后被改、QA 结论和测试证据。
- 交付完成、你认可后，说“做复盘”。它会列出候选经验，逐条请你确认，确认后才写入 `~/.agents/skills/industry-<行业>/`。

## 卸载
Mac：`sh ~/.dsh-delivery-kit/uninstall.sh`；Windows：`powershell -ExecutionPolicy Bypass -File "$HOME\.dsh-delivery-kit\uninstall.ps1"`。然后重启 DSH。行业经验包会保留。

## 文件
- `bundle/`：DSH 组合包（交付预设 + 默认预设设置 + 守卫插件 + 交付工作台 + 图标和名称）
- `skills/`：5 个技能（delivery-protocol、delivery-intake、independent-qa、industry-learning、project-retro）
- `install.sh` / `uninstall.sh`（Mac / Linux），`install.ps1` / `uninstall.ps1`（Windows）
