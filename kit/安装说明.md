# 交付模式 安装说明

给已经装好官方 DeepSeek Harness（DSH）的 Mac 用户。装好后，DSH 新会话默认是“交付”模式：先访谈确认验收标准，再计划、实现、独立验收、出报告，项目结束后可以复盘，把经你确认的经验存进行业经验包，下个同行业项目自动用上。

不需要注册账号。模型费用走你自己的 DeepSeek API Key（在 DeepSeek 开放平台充值、创建 Key）。

## 安装
1. 安装并打开一次 DeepSeek Harness。
2. 在终端进入本文件夹，运行 `sh install.sh`。
3. 完全退出 DSH（Cmd+Q）后重新打开。
4. 第一次使用时，在欢迎页选“添加 API Key”，粘贴你的 DeepSeek API Key。
5. 新建会话，确认智能体预设是“交付”。

## 使用
- 直接说要交付的成果：“帮我做一份 XX 行业的 XX 方案 / 做一个 XX 工具”。
- 它会先问几个业务问题，列出验收条目请你确认。
- 交付完成、你认可后，说“做复盘”。它会列出候选经验，逐条请你确认，确认后才写入 `~/.agents/skills/industry-<行业>/`。

## 卸载
`sh ~/.dsh-delivery-kit/uninstall.sh`，然后重启 DSH。行业经验包会保留。

## 文件
- `bundle/`：DSH 组合包（交付预设 + 默认预设设置 + 图标和名称）
- `skills/`：5 个技能（delivery-protocol、delivery-intake、independent-qa、industry-learning、project-retro）
- `install.sh` / `uninstall.sh`
