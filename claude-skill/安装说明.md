# omni-delivery：OmniAgent 交付框架的 Claude 技能版

把 OmniAgent（主交付 Agent "Orcus"）那套"访谈 → 验收合同 → 计划 → 实现 → 冻结 → 独立验收 → 诚实报告 → 复盘沉淀行业经验"的工作法，做成了一个 Claude 技能。内容来自之前做的 DSH 交付框架五个技能，合并成一个，并把 DeepSeek Harness 专属的部分换成了 Claude 的工具。

## 〇、从仓库打包 zip
```bash
cd claude-skill && zip -r omni-delivery.zip omni-delivery -x '*/__pycache__/*'
```

## 一、在 claude.ai（网页 / 桌面 / 手机 App）安装
1. 打开 设置 → 功能（Capabilities），确认"代码执行和文件创建"已打开（技能里的脚本要靠它运行）。
2. 在同一页的"技能（Skills）"里点"上传技能"，选 `omni-delivery.zip`（不要解压）。
3. 新开对话，直接说要交付的东西，例如"帮我做一份社区咖啡店开店方案，按交付流程来"。

## 二、在 Claude Code 安装
```bash
mkdir -p ~/.claude/skills
unzip omni-delivery.zip -d ~/.claude/skills/
```
装完新开一个 Claude Code 会话即可（项目级用法：解压到项目的 `.claude/skills/`）。

### 可选：打开"交付守卫"（只在 Claude Code 有效）
守卫会把几条规则变成硬拦截：冻结后不许改文件、版本号不许倒退、freeze.json 不许预填验收结论、主 Agent 不许自己写 QA 结论、没有 QA 结论不许写报告、经验包不许直接改。只在有 `.delivery/` 目录的项目里生效。

在 `~/.claude/settings.json` 里加：
```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Write|Edit|MultiEdit|NotebookEdit|Bash",
        "hooks": [{ "type": "command", "command": "python3 ~/.claude/skills/omni-delivery/hooks/guard.py" }]
      }
    ]
  }
}
```
已有 `hooks` 配置的话，把这一项并进 `PreToolUse` 数组。

## 三、怎么用
- **交付**：说出要做的成果。Claude 会先分 2–3 轮问业务问题，写一份需求摘要请你确认，再列出验收条目（每条带你的原话出处）请你确认，然后才开工。
- **验收**：Claude Code 里会派一个独立 QA 子 Agent 逐条核对；claude.ai 没有子 Agent，会做"角色切换式验收"，报告里会明确写"非独立验收"。
- **复盘**：你认可交付后说"做复盘"。Claude 会列出候选经验，**每条都要你确认、修改或拒绝**，确认的才写进行业经验包。

## 四、行业经验包
- 行业分两级：`行业/细分场景`，例如 `gov/data-platform`、`retail/coffee-shop`，经验包技能名是 `industry-retail-coffee-shop` 这样的格式。
- 严格脱敏：客户名、人名、金额、电话、邮箱、地址、IP、网址、密钥、内部系统名都会被脚本拦下，改掉才能入库。
- 旧经验被新证据推翻时标记为"已取代"并保留历史，不删除；用过的经验会打分（有用 / 中性 / 有害），有害次数多的会转为"待复查"。
- 存放位置：
  - Claude Code：自动写到 `~/.claude/skills/industry-<行业>-<场景>/`，下个同行业项目自动可用。
  - claude.ai：Claude 不能直接改你的技能，复盘后会给你一个 `industry-…-vN.zip`，你在 设置 → 技能 里上传（先删掉旧版本）。下次复盘前把旧 zip 发给它，否则历史经验会丢。

## 五、包里有什么
```
omni-delivery/
  SKILL.md                         主流程（交付协议）
  references/intake.md             需求访谈、验收条目草案
  references/delegation.md         子 Agent 角色和任务模板
  references/independent-qa.md     独立 QA 规则和派 QA 的模板
  references/industry-learning.md  使用行业经验
  references/project-retro.md      复盘、脱敏、逐条确认、合并
  references/omniagent-origins.md  每条规则对应的 OmniAgent 原设计
  scripts/delivery.py              合同检查、冻结、测试取证、QA 校验、状态门、报告检查
  scripts/lessons.py               经验包：新建、脱敏扫描、合并、打分、打包
  hooks/guard.py                   可选的 Claude Code 交付守卫
  assets/pack-template/            行业经验包模板
```

## 六、和原版的差别
- 没有内置 OmniAgent 的 gov / medical / legal 等锦囊原文（它们在你 Mac 的 `~/Claude逆向工程/omniagent/armories/`），需要的话可以改写成经验包加进来。
- OmniAgent 的后端强制检查，这里由 `delivery.py` 脚本和可选的守卫 hook 承担；claude.ai 上没有 hook，靠脚本检查和规则。
- 不涉及任何模型计费设置，用的就是你当前 Claude 账号。
