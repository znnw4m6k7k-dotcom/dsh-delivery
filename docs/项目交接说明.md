## 4. 关键技术事实（DSH 0.2.1-rc.5）
- 应用路径：`/Applications/DeepSeek Harness.app`。命令行：`…/Contents/Resources/runtime/cli/bin/dsh`。桌面版的 profile 名就叫 `desktop`，桌面版自带的命令行可以管理它。
- 安装组合包：`dsh plugin --profile desktop add <目录>`。补丁会叠加在官方 base 和 web 层之后，装完要重启 DSH。也可以在应用内用 `plugin_manager` 的 `install_bundle` 安装（需要用户批准）。
- 组合包格式：package.json 里的 `dsh.bundle.patch` 指向 cordis.patch.yml。补丁语法有 `insert`（新增行）和按 id 覆盖（config 整体替换）两种。
- 预设：`@deepseek-ai/dsh-agent-preset` 行。默认预设由 `agent-preset-registry` 的 `config.default` 决定，用户在设置里选的默认值优先。
- 技能目录：`dsh-skill-filesystem`，扫描 `.dsh/skills`、`.agents/skills`、`customSkillDirs`、`~/.dsh/skills`、`~/.agents/skills`。只发现顶层的 `SKILL.md`，嵌套的不算。
- Host 插件接口：`ctx.on('tools/pre-execute', async (exec,next)=>…)` 返回 `{kind:'allow'|'deny'|'ask'|'cancel'}`。exec 上有 `name`、`arguments`、`agent`、`parent`、`signal`。工作目录用 `ctx.get('workingDirectory').ensure(agent, signal)` 取；根 Agent 用 `ctx.get('agents').roots()` 判断。`tools/result (exec,result)` 拿 `result.isError` 和 `result.content`。工具名：`write`/`edit`（参数 `file_path`），`bash`（参数 `command`、`workdir`）。
- 免注册：欢迎页的“添加 API Key”走 dsh-llm-deepseek-api-key，不需要账号。DSH 是 MIT 许可（版权 DeepSeek），可以二次分发，但不能用 DeepSeek 商标。
- 做独立 App 需要：Apple Developer ID 签名和公证；关闭自动更新（download.deepseek.com）和强制更新策略（harness.deepseek.com）；更新 ElectronAsarIntegrity。
