## 给桌面 Agent 的「交付模式」v1.5.0

用 AI 做工具、写方案或做调研时，先和它确认什么算交付，再让它开工。做完后，用同一份验收清单逐条核对，并记录执行过的检查和待确认项。

这个版本让「装的到底是哪一版」变得可查：发版标签和插件版本从这版起统一，`/delivery-doctor` 多了一行构建信息。另外修掉了 DSH 版创建行业经验包时不校验技能名的问题。

## 这一版改了什么

- **版本号统一**：发版标签 `v1.5.0` 与包内 `version` 一致；发布流程会核对，不一致直接失败。之前 `v1.0.0` 和 `v1.1.0` 里的插件版本都是 `1.4.1`，导致自检结果一样、问题反馈对不上版本。
- **`/delivery-doctor` 增加「构建信息」**：显示发版标签和打包时间；源码安装会显示「没有 build.json」，不再和发版包混在一起。
- **DSH 版经验包命名校验**：`lessons.py new-pack` 现在要求 `--industry` / `--scenario` 是英文小写短横线，与 Claude / Codex 版一致。中文名请放在 `--title`。之前用 `--industry 餐饮` 会生成中文技能名，在本机能用、导到别的客户端会被拒。
- **单文件版 `delivery-contract.md` 进入发布资产**：上一版之后新增的单文件 Agent，现在可以直接从 Releases 下载。
- **发布说明按版本拆分**：放在 `docs/releases/<tag>.md`，不再所有版本共用一份。

## 选择安装包

| 文件 | 使用方式 |
|---|---|
| `dsh-delivery-kit.zip` | DeepSeek Harness。全部解压后，在 macOS 双击 `Install-Mac.command`，Windows 双击 `Install-Windows.bat`。重启 DSH 后使用“交付”预设。 |
| `delivery-contract-claude.zip` | Claude 网页或 App 可在技能设置中上传。Claude Code 用户解压到 `~/.claude/skills/`。 |
| `delivery-contract-codex.zip` | Codex。解压到客户端扫描的技能目录，例如项目的 `.agents/skills/`。 |
| `delivery-contract-generic.zip` | Cursor、Copilot、Gemini CLI、OpenCode、Windsurf、Devin Local 和其他支持 Agent Skills 的客户端。解压到客户端的技能根目录，保留完整的 `delivery-contract/`。 |
| `delivery-contract.md` | 单文件版。上传到任意会读取附件的 AI 工具，或把全文粘贴进对话或自定义指令。 |

有终端和文件权限的 Agent 可直接下载通用 ZIP，读取 `delivery-contract/SKILL.md` 并运行脚本。加载技能或单文件后，输入“请使用 delivery-contract，先帮我确认这项任务的验收标准”。[按工具能力选择用法](https://github.com/znnw4m6k7k-dotcom/dsh-delivery/blob/main/docs/纯对话快速开始.md)

**升级提示**：DSH 版重新运行一次安装即可，`/delivery-doctor` 的「插件版本」应显示 `1.5.0`、「构建信息」显示 `v1.5.0`。已经生成的行业经验包不受影响；如果里面已有中文名的包，需要重命名为 `industry-<英文slug>` 才能在其他客户端使用。
