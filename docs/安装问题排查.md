# 安装问题排查

按你看到的提示找对应的条目。都解决不了，请到 [Issues](https://github.com/znnw4m6k7k-dotcom/dsh-delivery/issues/new/choose) 选“安装问题”，把安装窗口里的全部文字贴上来。

先自检：装好后在 DSH 新会话里输入 `/delivery-doctor`，它会逐项告诉你哪里没装好。

---

## 1. 下载

**1.1 `curl` / `irm` 卡住、超时、提示连不上 GitHub**
国内网络访问 GitHub 不稳定。可以：
- 换个网络（手机热点常常可以）或开代理后重试；
- 或者用浏览器打开 https://github.com/znnw4m6k7k-dotcom/dsh-delivery ，点绿色的 **Code → Download ZIP**（或在 [Releases](https://github.com/znnw4m6k7k-dotcom/dsh-delivery/releases) 下载 `dsh-delivery-kit.zip`），解压后双击安装程序（见第 2 条）；
- 有能访问的镜像时，可以用 `DSH_KIT_URL` 指定压缩包地址：Mac `DSH_KIT_URL=<地址.tar.gz> sh install-online.sh`，Windows `$env:DSH_KIT_URL='<地址.zip>'` 后再运行在线安装命令。

**1.2 提示“安装包不完整”**
你可能只复制了安装脚本，或在压缩包里直接双击了文件。请把 ZIP **全部解压**，再运行解压出来的文件夹里的安装程序。

## 2. 打开安装程序

**2.1 Mac：双击 `Install-Mac.command` 提示“无法打开，因为无法验证开发者”**
右键（或按住 Control 点按）这个文件 → 打开 → 再点“打开”。只需要第一次这样做。
也可以在终端里运行：`sh ~/Downloads/dsh-delivery-main/kit/install.sh`（路径按你解压的位置改）。

**2.2 Mac：双击后提示“没有权限”**
在终端运行 `sh 解压目录/kit/install.sh`，用 `sh` 运行不需要执行权限。

**2.3 Windows：双击 `Install-Windows.bat` 弹出“Windows 已保护你的电脑”**
点“更多信息” → “仍要运行”。

**2.4 Windows：PowerShell 提示“因为在此系统上禁止运行脚本”**
不要直接运行 `install.ps1`，改用：双击 `Install-Windows.bat`，或者在 PowerShell 里运行
`powershell -ExecutionPolicy Bypass -File .\kit\install.ps1`。这只对这一次运行放开限制，不改系统设置。

**2.5 Windows：窗口里中文是乱码**
不影响安装结果。想看清楚提示，可以用 Windows Terminal 打开，或先运行 `chcp 65001`。

**2.6 不要用 sudo / 管理员身份**
Mac 上用 `sudo` 会装到管理员账户下，你自己的 DSH 看不到；脚本会拒绝这样运行。如果以前用 sudo 装过，先运行 `sudo rm -rf ~/.dsh-delivery-kit` 再重新安装。

## 3. 找 DSH

**3.1 提示“没找到 DeepSeek Harness”**
- 先确认已经安装 DSH，并且**打开过一次**；
- Mac：DSH 不在“应用程序”文件夹里时，这样指定位置：`DSH_APP="/你的路径/DeepSeek Harness.app" sh kit/install.sh`；
- Windows：找到 DSH 的安装目录（开始菜单里右键 DSH → 打开文件位置），然后
  `$env:DSH_APP='C:\你的安装目录'; powershell -ExecutionPolicy Bypass -File .\kit\install.ps1`；
- 已经知道 dsh 命令行在哪：直接用 `DSH_CLI=/路径/dsh`（Windows `$env:DSH_CLI='C:\路径\dsh.cmd'`）。

**3.2 提示“没有自带命令行，请升级”**
你的 DSH 版本太旧。到官方渠道升级到 0.2.1 或更新版本。

**3.3 命令行找不到，或装了总是失败：用应用内安装（任何系统都可以）**
在 DSH 里新建一个会话（用默认的“标准”预设），发送：

```
用 plugin_manager 的 install_bundle 安装 <安装提示里给出的 bundle 目录>
```

目录默认是 Mac `~/.dsh-delivery-kit/bundle`，Windows `C:/Users/你的用户名/.dsh-delivery-kit/bundle`。弹出批准提示时点同意，然后完全退出 DSH 再打开。

## 4. 装进 DSH

**4.1 提示“组合包没有注册成功”**
命令行运行了，但 DSH 的配置里没看到本组合包。按 3.3 用应用内安装。

**4.2 我有多个 profile（desktop / web）**
安装脚本会自动装进所有已有的 profile，只要你平时用的那个装上就行。只想装进其中一个：`DSH_PROFILE_NAME=desktop sh kit/install.sh`（Windows `$env:DSH_PROFILE_NAME='desktop'`）。

**4.3 提示没找到 `~/.dsh`**
说明 DSH 还没打开过。先打开一次 DSH，关掉后重新运行安装。

**4.4 重复安装 / 更新**
直接重新运行安装即可，文件会被替换，已装过的不会报错。

## 5. 装好之后

**5.1 新会话里看不到“交付”预设**
- 一定要**完全退出** DSH 再打开：Mac 按 Cmd+Q；Windows 在右下角托盘图标上右键“退出”。只关窗口不够。
- 如果你以前在设置里手动选过默认预设，在设置里把默认预设改成“交付”。
- 在会话里输入 `/delivery-doctor` 看自检结果。

**5.2 要不要注册账号？费用怎么算？**
不需要注册。第一次打开 DSH 时选“添加 API Key”，填入你在 DeepSeek 开放平台充值后创建的 API Key，模型费用直接从你的余额扣。

**5.3 提示没有 Python**
只有“做复盘、整理行业经验”时需要 Python，不影响安装和平时交付。
- Mac：终端运行 `xcode-select --install`；
- Windows：从 https://www.python.org/downloads/ 安装，安装时勾选 **Add python.exe to PATH**。Windows 上命令是 `py -3`，技能里已经提示 Agent 在 Windows 上改用它。

**5.4 守卫拦住了我的操作**
提示里会写原因和下一步怎么做。这是正常的保护（比如 QA 正在验收时不能改文件），按提示做或等 QA 返回即可。

## 6. 卸载

- Mac / Linux：`sh ~/.dsh-delivery-kit/uninstall.sh`
- Windows：`powershell -ExecutionPolicy Bypass -File "$HOME\.dsh-delivery-kit\uninstall.ps1"`

然后完全退出并重新打开 DSH。你的行业经验包（`~/.agents/skills/industry-*`）会保留。

## 7. Claude / Codex 版

**7.1 claude.ai / Claude App 上传 zip 提示格式不对**
要上传的是 `delivery-contract-claude.zip`（Releases 里下载），压缩包里第一层就是 `delivery-contract` 文件夹。不要上传整个仓库的 ZIP。

**7.2 Claude Code / Codex 里技能没出现**
确认目录是 `~/.claude/skills/delivery-contract/SKILL.md`（Codex 是 `~/.codex/skills/delivery-contract/SKILL.md`），然后**新开一个会话**。
