# 在任意 AI 工具里使用交付模式

根据你手上的工具能做什么，选下面一种方式。三种方式都沿用同一套交付合同流程。

## 能聊天、读附件或保存自定义指令

1. 打开 [单文件版 `delivery-contract.md`](../delivery-contract.md)，点击文件上方的 **Download raw file** 保存。也可以在文件页复制全文。
2. 把文件上传到新会话，或把全文粘贴到聊天或自定义指令。客户端拒收 Markdown 附件时，直接粘贴即可。
3. 输入“请按这份交付合同帮我做一个 CSV 销售汇总工具”。第一轮应收到针对输入、输出等需求的问题。明确确认验收条目后，Agent 才开始实现。

单文件包含完整的对话流程。只有聊天能力时，可以完成访谈、合同、计划、手工验收和复盘。需要执行测试、验证文件或独立 QA 的任务，按你当前工具能取得的证据报告。

## 能访问文件并运行命令

即使客户端没有“安装技能”按钮，也可以使用仓库里的 Python 工具。

1. 下载 [完整通用 ZIP](https://github.com/znnw4m6k7k-dotcom/dsh-delivery/releases/latest/download/delivery-contract-generic.zip)，解压到项目内或 Agent 能访问的工作区。若由 Agent 下载，使用同一个地址并将解压路径告诉它。
2. 请 Agent 读取解压后的 `delivery-contract/SKILL.md` 并按其流程处理任务。请保留同目录的 `scripts/`、`references/` 和 `assets/`。
3. 可以让 Agent 在项目根目录初始化 `.delivery/` 并查看状态，确认 Python 和工具路径可用。命令中的脚本路径按实际解压位置调整。

macOS / Linux（假设 ZIP 解压在项目根目录）：

```sh
python3 "./delivery-contract/scripts/delivery.py" init
python3 "./delivery-contract/scripts/delivery.py" status
```

Windows PowerShell：

```powershell
py -3 ".\delivery-contract\scripts\delivery.py" init
py -3 ".\delivery-contract\scripts\delivery.py" status
```

如果状态显示 `contract_required`，说明脚本已运行，正在等你确认交付合同。仓库脚本可以检查合同、冻结文件、收集测试证据和核对验收结论，也可以生成或更新行业经验包。独立 QA 仍取决于客户端权限。

用同一个通用 ZIP，按 [客户端技能安装说明](../README.md#安装其他-agent) 导入一次。之后新开会话就可以点名 `delivery-contract`。
