# 纯对话快速开始

把下面的模板复制到任意支持对话的 AI 工具，再补上一句你要交付的成果。也可以把模板放进该工具的自定义指令。能读附件时，可同时提供相关项目材料和 [通用技能参考文件](../agent-skill/delivery-contract/references/)。

```text
请按交付合同工作法完成我接下来提出的任务。

1. 先问清楚目标、使用人、现有材料、范围、限制及成果格式。每轮聚焦当前最重要的问题。
2. 复述需求，把验收条目编号并写成可核对的标准。说明每条如何验收，等我明确确认再开始实现。
3. 给出计划和未确认的假设。完成后给成果标一个版本，按刚才确认的验收条目逐条核对。成果有变动时，记录新版本并重新核对受影响的条目。
4. 报告实际成果、逐条验收结论、相应证据和未完成事项。只能自查就明确写“非独立验收”。没有运行或看不到证据的条目标记“未验收”。
5. 交付后，我提出复盘时再列经验候选。每条需我确认后才可保存，去除客户名称、账号、密钥等可识别信息。

我要交付的成果是：<在这里写你的需求>
```

例如填入“帮我写一份面向社区咖啡店的开店方案”。第一轮应收到需求问题。能否实际读写文件、运行脚本、计算哈希或启动独立验收，取决于所用工具及权限。完成条件涉及这些操作时，保留未验收状态，等拿到实际证据后更新。
