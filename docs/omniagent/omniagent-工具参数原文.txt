- props: path*, old_text*, new_text*, expected_replacements, file_sha256_before, old_text_sha256, anchor_text, anchor_sha256, symbol_name, symbol_kind
    path: Absolute path to the file to patch
    old_text: Exact text to replace
    new_text: Replacement text
    expected_replacements: Exact number of replacements expected. Defaults to 1.
    file_sha256_before: Optional SHA-256 hex digest of the whole file before editing. Rejects stale edits if the file changed since it was inspected.
    old_text_sha256: Optional SHA-256 hex digest of old_text. Rejects the patch if old_text was copied or transformed incorrectly.
    anchor_text: Optional exact surrounding text that must occur once. The replacement is scoped inside this anchor to disambiguate repeated old_text.
    anchor_sha256: Optional SHA-256 hex digest of anchor_text.
    symbol_name: Optional symbol name to scope the replacement. Supports Go, TypeScript/JavaScript, and Python declaration ranges; use anchor_text when uncertain.
    symbol_kind: Optional symbol kind such as function, method, or type.
- props: patch_path*, base_ref, allow_base_mismatch, action, apply
    enum action: ['preview', 'apply', 'rollback']
    patch_path: Patch file path returned by an isolated subagent worktree result. Relative paths resolve from the parent repository root.
    base_ref: Optional base Git ref from the isolated worktree result. When apply=true, the current HEAD must match unless allow_base_mismatch=true.
    allow_base_mismatch: Allow applying even when base_ref differs from the current parent checkout HEAD. Defaults to false.
    action: Patch action. Defaults to preview unless legacy apply=true is provided.
    apply: Legacy compatibility flag. If true and action is omitted, apply the patch to the parent checkout after the check passes.
